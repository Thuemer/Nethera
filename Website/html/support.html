Supportanfrage vorbereiten

Unser Support läuft über die GitHub-Issues des Nethera-Projekts. Du brauchst dafür ein GitHub-Konto. Prüfe zuerst, ob dein Problem bereits gemeldet wurde.

Deine Anfrage ist auf GitHub öffentlich. Teile keine Passwörter, Zugangsdaten oder persönlichen Netzwerkdaten. Dieses Formular sendet nichts automatisch: Du prüfst die Anfrage auf GitHub und veröffentlichst sie dort selbst.

Beschreibe deine Schritte, das erwartete Ergebnis und das tatsächliche Verhalten. Ergänze bei Bedarf Browser und Routermodell.
